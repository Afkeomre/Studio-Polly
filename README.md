## Особенности

- **Фиксированный хедер** - верхняя панель навигации остается видимой при скролле.
- **Hover-эффекты** - плавные переходы при наведении на кнопки и ссылки делают интерфейс более живым.
- **Бургер-меню для мобильных устройств** - на мобильных устройствах меню скрыто за значком бургера и раскрывается при нажатии на него.
- **Анимация баннера** - баннер с двумя большими текстовыми линиями, движущимися в противоположных направлениях, создает динамичный визуальный эффект. 
- **Кнопка `Bottom/Up`** - кнопка всегда видна на странице и меняет положение стрелки в зависимости от направления скролла. При нажатии прокручивает сайт вниз/вверх.
